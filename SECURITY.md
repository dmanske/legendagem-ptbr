# Segurança

Não publique chaves de API, arquivos `.env`, mídias privadas ou transcrições confidenciais.

Para relatar uma vulnerabilidade sem divulgar detalhes publicamente, abra contato privado com o mantenedor pelo perfil do GitHub. Não inclua credenciais reais no relato.

Se uma chave aparecer em commit, issue, conversa ou captura de tela, revogue-a no provedor e gere outra imediatamente. Remover apenas o texto não torna uma chave exposta segura novamente.
